# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment of any kind.
Disagreements about code are welcome; disrespect toward people is not.

Report conduct issues privately to the maintainer via
[GitHub](https://github.com/soummyaanon). Reports are handled
confidentially.
